# Language Bindings

High-level home for non-Rust packaging of SimpLineage.

The Rust FFI surface will live in `crates/simplineage-bindings`. Language-specific
project scaffolding (e.g. Python `pyproject.toml`, Node package) will be added
here as those integrations land.

| Target  | Status      | Notes                          |
|---------|-------------|--------------------------------|
| Python  | Planned    | PyO3 / maturin                 |
| Node.js | Planned     | N-API                          |
